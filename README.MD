Project Name

Short Project Description

A professional multi-page portfolio website designed to showcase my skills, projects, and contact information as a beginner web developer.

Purpose of the Website

The purpose of this website is to present my web development journey, highlight my projects, showcase my technical skills, and provide a way for potential employers, lecturers, and collaborators to contact me.

Features of My Project
Responsive navigation bar
Home page with profile picture and introduction
About Me page with personal information and career goals
Skills page with skill cards and icons
Projects page displaying project cards
Contact page with contact details and contact form
Footer with navigation links and social media links
